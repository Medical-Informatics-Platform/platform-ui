On that machine, run mip login --token and paste it. Scripts can set MIP_API_TOKEN instead, but every program started from there, AI assistants included, can read it.

A browser on any device

Run mip login. It shows a link and a code: open the link, sign in, check that the page shows the same code, and approve.

Never approve a code that someone else sent you.

Then, in Python:

import mip
client = mip.Client.from_env()

Each sign-in lasts at most 6 months, and ends after 30 days without use. To end it sooner, run mip logout on that computer. Without that computer, remove "MIP command line" under Applications in your sign-in account: that ends every computer's sign-in.
