  1. Create API token

    In Permissions, enter custom:mip-platform-token and choose an expiry. The token is shown once. You can revoke it on the same page.

  2. In a terminal on your computer, run: 
    {{ setupSnippet }}

    Then start Python in the same terminal and run:

    import mip; client = mip.Client.from_env()
